## 📊 Overview

This repository contains a comprehensive customer satisfaction analysis for Dano Airline based on **130,000 passenger responses**. The dashboard provides a full view of customer experience, identifying key drivers of satisfaction, service gaps, and actionable recommendations.

| Metric | Value |
|--------|-------|
| Total Passengers | 130,000 |
| Satisfied / Dissatisfied | 56K / 73K |
| Overall Satisfaction | 3.28 / 5.0 |
| Top Rated Service | In-flight (3.64) |
| Lowest Rated | WiFi (2.73) |
| Most Satisfied Age Group | 66+ (82%) |
| Least Satisfied Age Group | 18–25 (35%) |

## 🔍 Key Insights

| Insight | Finding |
|---------|---------|
| **Class** | Economy: 50% satisfied vs Economy Plus: 71%, Business: 67% |

| **Flight Status** | Delayed flights: 42% satisfied vs On-time: 52% |
| **Service** | WiFi (2.73) and Online Booking (2.76) lowest rated |
| **Age** | 18–25: 35% satisfaction (lowest); 66+: 82% (highest) |
| **Customer Type** | Returning: 74%; Business: 89% satisfaction |

## 🎯 Strategic Recommendations

| Priority | Insight | Recommended Action |
|----------|---------|-------------------|
| 🔴 High | Economy highest dissatisfaction | Review Economy cabin experience: seat comfort, meals, dedicated service staff |
| 🔴 High | Business travelers less satisfied | Targeted survey, priority boarding, express check-in, corporate perks |
| 🔴 High | Delayed flights reduce satisfaction | Real-time communication, proactive rebooking, optimize ground operations |
| 🟠 Medium | WiFi and Online Booking lowest | Upgrade WiFi infrastructure, simplify online booking UI/UX |
| 🟠 Medium | 18–25 lowest satisfaction | Social media engagement, youth-friendly perks, improved app experience |
| 🟢 Low | Gate Location and Online Booking below 3.0 | Review gate assignment, improve wayfinding signage |
